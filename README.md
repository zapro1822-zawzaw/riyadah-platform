# رُوّاد V8
نسخة static جاهزة للنشر على Vercel/GitHub. لا توجد src ولا build.

المكونات: لوحة قيادة، ملفات المتعلمين، رائز المستوى الخامس، TaRL رياضيات مسار1/2، شبكات التتبع والطلاقة، الدعم المكثف والممتد، مولد خريطة من PPTX، تقارير قبلي/بعدي، مواكبة المفتشة، إعدادات المؤسسة، CSV، نسخ احتياطي واسترجاع.

ملاحظة: هذه أداة تنظيم وتدبير تربوي وليست منصة رسمية للوزارة، ويجب اعتماد الوثائق الرسمية عند أي تقييم إشهادي.
