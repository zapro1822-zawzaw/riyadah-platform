# رَوّاد V16

منصة سحابية متكاملة لمؤسسات الريادة، Mobile First، جاهزة لـ GitHub/Vercel.

## النواة
- Supabase Auth + PostgreSQL + RLS.
- صلاحيات: مالك المنصة، مدير، أستاذ، مفتش، ولي أمر.
- 18 وحدة قابلة للتوسع.
- مركز تطوير مستقبلي حصري لمالك المنصة.
- تعدد اللغات: العربية / الفرنسية / الإنجليزية.

## الوحدات التربوية
لوحة القيادة، الأقسام، التلاميذ والملف الفردي، الروائز والتقويم، مسارات الدعم، لبنات التعلم والتصديق، التعليم الصريح، العربية، الفرنسية، الرياضيات، الطلاقة، التتبع، التقارير، الموارد والجذاذات، التأطير والمفتشة، بوابة الآباء، الذكاء الاصطناعي، ومركز التصدير.

## التعليم الصريح
النواة تدعم: الهدف، المكتسبات السابقة، النمذجة (Je fais)، الممارسة الموجهة (Nous faisons)، الممارسة المستقلة (Vous faites)، التحقق من الفهم، التقويم، والمعالجة والدعم.

## الذكاء الاصطناعي
تم إنشاء AI Hub وقاعدة تسجيل المخرجات. ربط نموذج الذكاء الاصطناعي الفعلي يجب أن يتم من خلال خادم آمن ومتغيرات بيئة، ولا توضع مفاتيح API السرية داخل المتصفح.

## بوابة الآباء
حساب مستقل لولي الأمر، مع ربطه بالأبناء من طرف المؤسسة، وعرض الملفات والنتائج والدعم والرسائل حسب الصلاحيات.

## التصدير
JSON وCSV والطباعة/PDF في النواة، مع قابلية إضافة Word/Excel/صور وZIP في الوحدات المتخصصة.

## النشر
المستودع مرتبط بـ Vercel. لا حاجة إلى مجلد `src` أو build مع هذه النسخة الثابتة الحالية.
