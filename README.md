# رُوّاد — النسخة النهائية V5
منصة Mobile First لمؤسسات الريادة.

## التثبيت
1. فك الضغط.
2. ارفع محتويات المجلد إلى مستودع GitHub جديد.
3. تأكد أن `package.json` و`index.html` و`vercel.json` في الجذر، ومجلد `src` في الجذر.
4. في Vercel اختر المستودع.
5. Framework: Vite — Build: `npm run build` — Output: `dist`.
6. Deploy.

## أهم الإصلاحات
- لا يوجد خطأ `page/learners/groups already declared`.
- كل التنقلات مرتبطة بصفحات فعلية.
- حفظ تلقائي عبر LocalStorage.
- إضافة/تعديل/حذف المتعلمين والأقسام.
- الرائز القبلي والبعدي.
- الدعم المكثف والتتبع والطلاقة.
- التقارير والتصدير CSV/JSON والطباعة.
- النسخ الاحتياطي والاسترجاع.
- الوضع الليلي.
- مولد خرائط ذهنية من نص متعدد الأسطر.
- روابط Classroom وCanva ومسار.
- تصميم متجاوب للهاتف والكمبيوتر.

> هذه النسخة تعمل دون قاعدة بيانات خارجية؛ البيانات محفوظة على الجهاز الذي تستخدمه. للبيانات المشتركة بين عدة أجهزة يلزم Backend لاحقاً.
