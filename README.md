# رَوّاد V9 — النسخة النهائية

نسخة Static Mobile First جاهزة لـ GitHub/Vercel، بدون مجلد `src` وبدون build.

## الوحدات
لوحة القيادة، الأقسام، المتعلمون والملف الفردي، الدعم المكثف ومجموعاته، الرائز القبلي والبعدي للمستوى الخامس، شبكات التتبع، شبكات التصديق على لبنات الرياضيات، شبكات الطلاقة، التقارير والطباعة وCSV/JSON، ملف المفتشة المؤطرة، روابط Classroom/Canva/مسار، النسخ الاحتياطي والاسترجاع، ومولد خريطة ذهنية تلقائي من PPTX.

## التثبيت
ارفع `index.html` و`README.md` إلى جذر مستودع GitHub. في Vercel اربط المستودع واترك Root Directory هو الجذر. لا تحتاج إلى `src` ولا إلى build.

> البيانات تحفظ محلياً في المتصفح. النسخة فارغة من بيانات المتعلمين والنتائج السابقة.
