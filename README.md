# رَوّاد V17

منصة سحابية لمؤسسات الريادة، Mobile First، مرتبطة بـ Supabase وVercel.

## ما تم بناؤه
- مصادقة سحابية وصلاحيات حسب الدور.
- مدير، أستاذ، مفتش، ولي أمر، وفضاء تطوير حصري للمالك.
- لوحة قيادة ومؤشرات وتنبيهات.
- الأقسام والتلاميذ والملف الفردي التراكمي.
- الروائز والتقويم.
- TaRL ومسارات أساس/متوسط/تحدي.
- اللبنات والإشهاد.
- التعليم الصريح: النمذجة، الممارسة الموجهة، المستقلة، التحقق، التقويم والمعالجة.
- العربية والفرنسية والرياضيات والطلاقة والتتبع.
- التقارير والتصدير JSON/CSV/Word-compatible والطباعة/PDF.
- مساعد تربوي قائم على بيانات المنصة مع fallback محلي آمن.
- مولد خرائط ذهنية من النص وPPTX عبر استخراج نص الشرائح.
- بوابة الأسرة مع ربط الأبناء.
- واجهة عربية/Français/English.

## ملاحظة مهمة
النسخة الحالية cloud-first ولا تعتمد على LocalStorage كقاعدة بيانات. مفاتيح Supabase الموجودة في الواجهة هي المفاتيح العامة فقط. أي نموذج AI خارجي حقيقي يجب ربطه من جهة الخادم عبر متغير بيئة سري.

## النشر
المستودع مرتبط بـ Vercel، وكل تغيير على `main` يعاد نشره تلقائياً عند تفعيل تكامل GitHub.
